关于跨域（CORS）：后端已放行，普通浏览器直接用即可

✓ 已配置 —— 后端两个入口都放行了跨域，你用 普通浏览器 打开本页面即可直接压测， 不需要再折腾 --disable-web-security 启动参数。

  • service-order（:8083）：直接压测本服务时生效。
  • service-gateway（:8080）：走网关时生效（注意网关接口需要带令牌）。

仍然报「网络错误」怎么办？按顺序排查：

  1. 确认目标服务已启动（例如 127.0.0.1:8083 能通）。
  2. 后端改了 CORS 配置后需要重新打包并重启服务才生效。
  3. 浏览器 Network 面板里看该请求的响应头：正常应能看到 Access-Control-Allow-Origin； 若没有该头 → 后端 CORS 未生效；若该头出现两次 → 同时走了网关与服务各自的 CORS，需删掉其中一处。
  4. 应急手段（不推荐，仅临时排障）：用独立数据目录起一个关闭同源策略的浏览器实例。
