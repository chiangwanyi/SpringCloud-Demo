## 完善 service-system 模块 + 新增 service-system-api 模块
- 目标：MyBatis-Plus 增删改查（Mapper 用注解 @Select 等，不用 XML）、加启动类与测试类；新增 service-system-api（DTO + Feign）对外提供用户信息接口。
- 结构：
  - service-system-api：com.jwy.scd.api.SysUserApi（@FeignClient + @RequestMapping，契约接口）、com.jwy.scd.api.dto.UserInfoDTO（脱敏，不含 password）。
  - service-system：entity.SysUser（@TableName sys_user）、mapper.SysUserMapper（extends BaseMapper + 注解 @Select）、service.ISysUserService/impl（extends IService）、controller.SysUserController（implements SysUserApi）、ServiceSystemApplication（@MapperScan）、SysUserCrudTest（@SpringBootTest 验证 CRUD）。
- 依赖坑（关键，环境是 Spring Boot 4.0.8 / Spring Framework 7.0.9）：
  1. mybatis-plus 必须用 **mybatis-plus-spring-boot4-starter:3.5.16**（不要用 mybatis-plus-boot-starter 3.5.3.1，会拉 mybatis-spring 3.x，与 Spring 7 的 factoryBeanObjectType 冲突报 Invalid bean definition）。
  2. 必须显式加 **com.h2database:h2**（runtime），否则 H2 驱动加载失败。
  3. service-system-api 里的 spring-cloud-starter-openfeign 设为 **<optional>true</optional>**，避免实现模块传递引入 spring-cloud 自动配置（SimpleDiscoveryClientAutoConfiguration 在 Boot 4 下条件处理崩溃）。openfeign 固定 4.1.0（本地仓库无与 Boot4 匹配的 spring-cloud BOM）。
  4. 测试用 H2 内存库（src/main/resources/schema.sql + application.yml），@SpringBootTest(webEnvironment=NONE)。
- 验证：./mvnw -pl service-system -am test → BUILD SUCCESS，Tests run: 1, Failures: 0, Errors: 0。
- 说明：测试/演示资源（schema.sql、application.yml）在本任务执行期间曾被外部进程清掉，已重建到 src/main/resources（运行与测试共用）。
