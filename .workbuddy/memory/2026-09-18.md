## 项目重构：单模块 Spring Boot → 微服务父工程（聚合工程）
- 根 `pom.xml` 改为 `packaging=pom`（聚合 + 父工程），不再产出 jar；应用代码与 `spring-boot-maven-plugin` 下放到子模块。
- 新建子模块 `springcloud-demo-service`（默认 `packaging=jar` + `spring-boot-maven-plugin` repackage），包含原 `SpringcloudDemoApplication` 与 `application.yaml`（应用名改为 `springcloud-demo-service`）。
- 根 POM 用 `<pluginManagement>` 统一定义 `spring-boot-maven-plugin` 与 `maven-compiler-plugin`（Lombok 注解处理器），子模块按需继承。
- 已删除原根 `src/` 与旧 `target/`。
- 验证说明：本沙箱无 JDK 且构建工具不可用，未实际执行 `mvn package`；需在本地用 `mvn clean package` 验证父工程不产出 jar、子模块产出可执行 fat jar。
